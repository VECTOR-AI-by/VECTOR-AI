# VECTOR-AI

> **Суверенная AI-система нового поколения для автономного аудита критической инфраструктуры, государственных информационных систем и Web3-активов.**

VECTOR-AI (Vulnerability Extraction & Contract Transaction Operation Router) — это первое суверенное MAS-решение (Multi-Agent System) в СНГ, объединяющее 19 перекрёстных слоёв анализа под управлением единого оркестратора.

## Ключевые характеристики

- **19 перекрёстных слоёв анализа** — от статического разбора кода до OSINT-разведки
- **12 языков программирования** + 6 движков статического анализа
- **9+ блокчейн-сетей** с поддержкой нативной экосистемы каждой
- **0 внешних API** — полная независимость от зарубежных облачных провайдеров
- **Аудит через одноразовые контейнеры-сателлиты** в периметре заказчика

## Архитектура (высокоуровневая)

Изолированное ядро роя функционирует на защищённых мощностях разработчика. При инициации аудита в инфраструктуре заказчика разворачивается временный Docker-контейнер-сателлит, через который рой проводит анализ без выкачивания данных наружу. После верификации контейнер автоматически удаляется.

```
[ Вход ] → [ Archetype Gate ] → [ Оркестратор ]
                                       │
                            ┌──────────┴──────────┐
                            ▼                      ▼
                       [ ALPHA ]              [ GAMMA ]
                       Web3 / Code            Infra / OSINT
                            │                      │
                  ┌─────────┼──────────┬──────────┐
                  ▼         ▼          ▼          ▼
              [ web3-  ] [ Nmap +  ] [ OSINT-  ] [ Spawner ]
              [ сканер ] [ арсенал ] [ парсеры ]  [ Watchdog ]
                            │
                            ▼
                  [ Target Ledger (PostgreSQL) ]
                            │
                  ┌─────────┴──────────┐
                  ▼                    ▼
        [ Interpreter-воркеры ]  [ Verifier-воркеры ]
        (массовая фильтрация)   (Anvil/Foundry Fork)
                            │
                            ▼
                  [ Tech Verdict + Legal ]
```

## Применение

- **Государственные структуры / регуляторы** — контроль защищённости КИИ
- **Банковская сфера** — due diligence смарт-контрактов и FinTech-систем
- **Web3 / DeFi проекты** — пред-деплоймент аудит и drift-мониторинг
- **Корпоративный сектор** — контроль внешнего периметра и OSINT-разведка

## Суверенитет

- **100% On-Premises** — никакие логи, исходный код или транзакционные данные не уходят во внешние SaaS-облака
- **Изолированный AI-Runtime** в Docker с собственной системой Watchdog и Spawner
- **Каскадная фильтрация** — массовая фильтрация на Interpreter-слое + точечная верификация на Verifier-слое (без воздействия на продакшен заказчика)
- **Target Ledger** — отдельная СУБД для контекста, не нагружающая LLM-память
